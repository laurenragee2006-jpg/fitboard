# fitboard

Had the idea at like 2am and wrote it down in my notes app so I wouldn't 
forget. Woke up and built it.

Fitboard is a virtual outfit builder. You upload photos of your clothes, 
the background gets removed automatically, and you can drag them onto a 
silhouette to put together outfits. Save the ones you like and come back 
to them later.

Still actively adding features.
